# vemcert-vocab

Published vocabulary for Vemcert verifiable credentials, served by GitHub Pages
(https://gasmsyteacher.github.io/vemcert-vocab/) as the redirect target of the permanent identifier `https://w3id.org/vemcert/v1#`.

| File | Purpose |
|---|---|
| `v1.jsonld` | JSON-LD context (`Accept: application/ld+json`) |
| `v1.html` | Human-readable term reference (`Accept: text/html`) |
| `index.html` | Version index |

## A publishing target, not a source of truth

Every file here is generated by `ops/scripts/publish_vocab.py` in the Vemcert
platform repository from `docs/vocab/v1.jsonld`, the definition that sits next
to the code embedding these terms in signed credentials. Edit there, rebuild, and
push here; never edit here.

Nothing fetches these files at runtime: credentials carry their term definitions
inline. This is documentation with a permanent URL.

## Stability

`v1` is immutable. Terms may be added; a term's meaning is never changed and a
term is never removed. Breaking changes mint `/v2`.

Formerly published as `cachet-vocab` (the product's earlier name); no permanent
identifier was ever registered under that name.
